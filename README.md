# ![Icon](icon.png) nZombies Chronicles

A WIP fork, continuation, and successor to [Zet0r's nZombies](https://github.com/Zet0rz/nzombies)

* Holds incredibly high standards
* Stays true to classic gameplay
* Fixes the mode without completely changing it
    * Fixes bugs 👟🐛
    * Adds optimization 🏃
    * Improves stability 💪
    * Enhances Multiplayer Compatibility 🌐

## Dependencies

* [Addon Collection](https://steamcommunity.com/sharedfiles/filedetails/?id=3378413470)

Note: some stuff might be missing and they have been excluded over copyright concerns. You'll have to fix content errors yourself.

## Singleplayer Compatibility

nZombies is always tested in Singleplayer and can be played offline with minimal problems.

## Server Compatibility

nZombies Chronicles was specifically built to run on dedicated servers. It was built because the Multiplayer experience is far too broken on any other version of nZombies.

It has garnered a lot of real world server usage and was used by the popular nZC Servers between 2020-2024, during which it was #1 with over 10,000 unique players!
